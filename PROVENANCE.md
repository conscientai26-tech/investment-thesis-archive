## Evidence Structure

The dating and development of the research are documented through:

1. GitHub commit timestamps
2. GitHub file history
3. The date written inside the research document
4. The Google Drive creation and modification history
5. Dated future updates and revisions

Using more than one platform makes the historical record easier to verify and reduces dependence on a single source.

## Revision Policy

Original theses and portfolio decisions should not be silently rewritten after publication.

Permitted non-substantive edits include:

- grammar corrections
- formatting improvements
- repaired links
- clearer wording
- source additions that do not change the original conclusion

Substantive changes must be documented through:

- a new dated section
- a separate update file
- a clearly described Git commit
- or a new version of the original document

New evidence must not be presented as though it had already been known at the original publication date.
