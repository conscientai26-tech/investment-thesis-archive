# Pilot Portfolio Normalization

I started the investment record under a different sizing system.

The original framework was based on roughly 100,000 of virtual capital, with around 3,000 available for new investments per month.

On August 9, I changed the portfolio framework and moved to a fixed USD 1,000,000 reference portfolio.

Because of that, the old nominal position sizes are not directly comparable with the new ones.

For comparison purposes, I will therefore normalize the early positions to the current portfolio scale.

The conversion factor is 10x.

The original Microsoft position of 600 stays exactly as it was recorded. The date, entry price and original amount do not change.

On the current portfolio scale, that position is equivalent to 6,000.

The same rule applies to the earlier Alphabet position:

original allocation x 10 = current-scale equivalent.

This is not a new trade and it does not change the historical record. It is only a way to compare positions that were made under two different portfolio sizes.

From now on, early positions can therefore be shown with both numbers:

Original allocation

Current-scale equivalent

The original number remains the historical record. The normalized number is used only for comparison with the current USD 1,000,000 portfolio.
